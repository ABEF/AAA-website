# NFT evolution audio

User-supplied ACTI (`acti.mp3`) is used for activation; EV (`ev.mp3`) for later
upward tier changes. The original files are preserved outside this repository.

| Public asset | Original interval retained | Duration |
| --- | --- | --- |
| activation.mp4 | 0.060–3.750 seconds | 3.690 seconds |
| evolution.mp4 | 0.065–1.490 seconds | 1.425 seconds |

Only surrounding silence was removed. No time stretching, pitch change or
synthetic replacement. ACTI's full audible sound was explicitly approved despite
the earlier 1.5-second limit. EV remains below that limit. AAC at 160 kbps in an
audio-only MP4 container preserves compatibility with the current local fixture
asset allowlist. This documentation file is excluded from the public build.

Playback starts with the confirmed image reveal, only after successful LP
execution and a refreshed higher LP value/evolution. Approval, claims, failed
transactions and same-tier additions stay silent. See FRONTEND_STATE.md.
